52Hz Backups

52Hz Backups — служебное приложение для резервного копирования данных музыкальной школы «52 герца».

Приложение использует Google Drive API и rclone для автоматического сохранения зашифрованных резервных копий.

Доступ предназначен только для администратора системы.
