Политика конфиденциальности 52Hz Backups

Дата обновления: 19 ноября 2026 года.

1. Назначение приложения

52Hz Backups — служебное приложение для резервного копирования базы данных музыкальной школы «52 герца». Приложение предназначено для использования администратором системы.

2. Доступ к Google Drive

Приложение использует Google Drive API через rclone для загрузки и управления резервными копиями после авторизации владельца Google-аккаунта.

3. Использование данных

Доступ к Google Drive используется только для хранения, проверки и восстановления резервных копий. Приложение не использует данные Google для рекламы, продажи данных или обучения моделей искусственного интеллекта.

4. Защита информации

Перед отправкой в Google Drive резервные копии шифруются средствами rclone crypt. OAuth-токены сохраняются в защищённой конфигурации на сервере администратора.

5. Передача данных

Зашифрованные резервные копии хранятся в Google Drive. Приложение не предоставляет доступ к ним другим пользователям.

6. Удаление данных

Администратор может удалить резервные копии из Google Drive и отозвать доступ приложения в настройках безопасности своего Google-аккаунта.

7. Обратная связь

По вопросам приложения можно обратиться через страницу проекта на GitHub . Не публикуйте персональные данные в открытых обращениях.
